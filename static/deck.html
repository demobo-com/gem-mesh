Clone it, install it, talk to it

On your Mac Apple silicon, 8 GB or more · 10 minutes + download
1

Clone

git clone https://github.com/demobo-com/gem-mesh.git gem-mesh

then cd gem-mesh

2

Install

./install.sh

Picks the Gemma 4 that fits your Mac, E2B to the 26B, and runs it as a mesh node.

3

Talk to it

gem-mesh

Demo files are in demo/files/; naming one attaches it.

4

Pair a phone

gem-mesh pair

Shows the address, checks and a QR code.

On your Android phone Android 11+, 8 GB recommended · over USB until the APK ships
1

Install the app

cd clients/android && ./gradlew installDebug

USB debugging on; Android Studio once for the SDK.

2

Open it on Wi-Fi

It downloads Gemma 4 E4B (3.7 GB) once, then runs it on the phone.

3

Find your Mac

Settings → Your Mac. On the same Wi-Fi it appears by itself; or scan the QR.

Optional: a bigger node Linux + NVIDIA, M5 Ultra Mac Studio, or any spare Mac
1

Same repo

Clone it on that machine, on the same Wi-Fi.

2

Install as a node

./install.sh --role workstation

Linux with NVIDIA is detected without the flag.

3

Nothing else

Your Mac and phone find it; gem-mesh nodes lists it.
