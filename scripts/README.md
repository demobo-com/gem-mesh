# scripts

- `install.sh`: one-command setup (the repo root's `install.sh` calls it). On a Mac it sizes the models to the
  memory, sets up the laptop node and the phone stand-in, and registers `com.gem-mesh.node`. `--help` for options.
- `e2e-actions.sh`: file and photo actions in both chats, with approvals (about 2 minutes, needs the Mac's node).
